# Saffron & Hearth — Restaurant Website

A responsive restaurant webpage built with **HTML**, **CSS**, and **JavaScript** featuring a hero section, categorized food menu, special dining offers, customer reviews, and a table reservation section.

## Features
- **Responsive Navigation & Mobile Menu**: Clean header with smooth scrolling and a toggleable mobile menu.
- **Hero Section**: Highlights wood-fired culinary craft, ratings, produce quality, and daily hours.
- **Categorized & Filterable Menu**: Includes Artisanal Starters, Signature Main Courses, and Desserts & Craft Beverages with category filter buttons.
- **Special Offers**: Seasonal combo deals with discounted pricing and quick offer selection into the reservation form.
- **Customer Reviews**: Diner testimonials with star ratings.
- **Location & Table Reservations**: Restaurant address, opening hours, contact info, and an interactive reservation form.

## Tech Stack
- HTML5 (`index.html`)
- CSS3 (`style.css`)
- JavaScript (`script.js`)

## How to Run Locally
1. Download or clone the repository.
2. Open `index.html` in any web browser.

## Live Deployment (GitHub Pages)
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
